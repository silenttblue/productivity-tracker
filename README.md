# Productivity Tracker – Task Manager Web App

A simple yet powerful task manager built completely from scratch 
using vanilla HTML, CSS and JavaScript — no frameworks or libraries.

## Features

- Add tasks with due dates and priority levels (High, Medium, Low)
- Color coded borders — Red for High, Yellow for Medium, Green for Low
- Due date badge on each task with automatic red highlight 
  if deadline has passed
- Tasks grouped by Today and Yesterday
- Undo feature with a 2.5 second window to recover a completed task
- All data saved in localStorage — nothing is lost on page refresh

## Tech Stack

- HTML
- CSS
- JavaScript (Vanilla)
